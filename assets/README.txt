Place your shop logo here as `icon.ico` for the Windows executable icon.

For best results, use a 256x256 pixel `.ico` file with multiple sizes embedded.

You can convert any PNG to ICO using:
  - https://convertico.com/
  - Or using Python: pip install Pillow && python -c "from PIL import Image; img = Image.open('logo.png'); img.save('icon.ico')"
